# 오뿌

매일 어떤 향수를 사용했는지 달력에 남기는 **모바일 우선 설치형 웹 앱(PWA)** 입니다. 기록은 서버가 아니라 사용 중인 기기의 브라우저에 저장되며, JSON 파일로 백업하고 복원할 수 있습니다.

## 실행하기

별도 설치 의존성이 없습니다. 저장소 폴더에서 정적 웹 서버만 실행하세요.

```bash
npm start
```

브라우저에서 `http://localhost:4173`을 엽니다. 테스트는 다음 명령으로 실행합니다.

```bash
npm test
```

> 파일을 직접 더블클릭하지 말고 HTTP 서버로 실행해야 오프라인 캐시와 설치 기능이 정상 작동합니다.

## 스마트폰에서 앱으로 받기

PWA 설치에는 이 프로젝트를 **HTTPS 주소에 배포**해야 합니다. GitHub Pages, Netlify, Cloudflare Pages 등 정적 호스팅에 저장소를 연결한 뒤 발급된 HTTPS 주소를 휴대폰에서 여세요.

### iPhone / iPad

1. HTTPS 주소를 **Safari**로 엽니다.
2. 하단의 **공유** 버튼을 누릅니다.
3. **홈 화면에 추가** → **추가**를 누릅니다.
4. 홈 화면의 `오뿌` 아이콘으로 실행합니다.

### Android

1. HTTPS 주소를 **Chrome**으로 엽니다.
2. 오른쪽 위 메뉴(⋮)에서 **앱 설치** 또는 **홈 화면에 추가**를 누릅니다.
3. 설치를 확인하고 홈 화면의 `오뿌` 아이콘으로 실행합니다.

설치 후 한 번 열었던 화면은 서비스 워커 캐시 덕분에 오프라인에서도 실행할 수 있습니다. 기록은 브라우저별·기기별로 분리되므로 기기를 바꾸거나 브라우저 데이터를 지우기 전, **향수장 → 내 데이터 → JSON 내보내기**로 백업하세요. 새 기기에서는 같은 메뉴의 **가져오기**를 사용합니다.

## 제공 기능

- 날짜 선택 → 여러 향수 선택 → 한 번에 저장, 수정 및 삭제
- 같은 향수의 하루 사용 횟수와 메모 기록
- 향수장 검색, 테마 변경, 향수장에서 제거해도 과거 기록 보존
- 월별·계절별 사용 일수/횟수, 향수 순위와 테마 비중
- 브라우저 로컬 저장과 형식 검증을 거치는 JSON 백업/복원
- 홈 화면 설치, 독립 실행, 오프라인 실행을 위한 PWA 구성

## 데이터 주의사항

기본 목록은 기능 시연을 위한 소규모 자체 목록이며 외부 향수 데이터 서비스와 연결되어 있지 않습니다. 로그인이나 클라우드 동기화도 제공하지 않습니다. 중요한 기록은 정기적으로 JSON 백업을 보관하세요.
